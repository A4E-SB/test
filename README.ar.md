## ✨ الميزات

| الوحدة | الوصف |
|---|---|
| 📊 **لوحة التحكم** | ملخص اليوم (الطلبيات، الإرساليات، الطلبيات الوهمية)، تنبيهات النصب، مخطط الإيرادات مقابل الخسائر (6 أشهر)، نسبة الإتمام، المال الموفَّر |
| 👥 **الزبائن** | قاعدة كاملة مع **نقطة ثقة تلقائية (0-100)**، تصنيفات تلقائية (موثوق / شبح / نصاب / مضيع وقت / جديد)، سجل الطلبيات، الخسائر لكل زبون |
| 📦 **الطلبيات** | دورة كاملة (انتظار ← مؤكدة ← مُرسلة ← موصّلة ← مدفوعة) + حالات الاحتيال (وهمية، مرفوضة، الهاتف مغلق، دفع مزيف، ملغاة، **محجوبة**)، تصفية حسب الحالة/الولاية/التاريخ |
| 🔍 **كاشف الوصولات المزيفة** | تحليل محلي لصور BaridiMob: قراءة ضوئية OCR، بصمة الصورة (dHash) ومطابقتها مع الوصولات المزيفة المعروفة، فحص الميتاداتا (آثار PicsArt/Snapseed)، تناسق الخط (OpenCV)، تحليل ELA، فحص صيغ التاريخ والمرجع والمبلغ. النتيجة **حقيقي / مشبوه / مزيف** مع الأسباب |
| ⏳ **مضيعو الوقت** | تسجيل كل تواصل، نسبة التحويل، اقتراح تلقائي لمتى تطلب **تسبيقاً**، ردود ذكية جاهزة بالعربية والفرنسية للنسخ في ماسنجر/واتساب |
| 💰 **التقارير المالية** | الإيرادات، المصاريف، الربح الصافي، تفصيل الخسائر (وهمية / رفض / دفع مزيف)، المال الموفَّر بفضل الحجب. تصدير CSV / Excel |
| 🔌 **استيراد/تصدير USB** | **ملف `.hma`**: القائمة السوداء الرسمية لحماية، تُشارك بين البائعين عبر فلاشة. استيراد وتصدير الطلبيات CSV / Excel |
| 🖨️ **بطاقات التوصيل** | PDF بمقاس A6 أو 100×100 مع مستوى الخطر بالألوان، باركود، وتحذيرات («اتصل قبل التوصيل») |
| ⚙️ **الإعدادات** | لغة الواجهة: عربية/فرنسية/إنجليزية، معلومات CCP/BaridiMob (للتسبيقات)، شركة التوصيل الافتراضية، نسخ احتياطي/استعادة، كل الـ58 ولاية مدمجة |
| 🛒 **المنتجات والمخزون** *(جديد v1.1)* | منتجات بسعر شراء/بيع وهامش، مخزون تلقائي (محجوز لكل طلبية نشطة، يُرجع عند الإلغاء)، تنبيهات المخزون المنخفض، **الربح الحقيقي** بعد التكاليف |
| 💰 **التسبيقات** *(جديد v1.1)* | تتبع التسبيقات مع حالة « في انتظار التسبيق »؛ الملصق يطبع **المتبقي للدفع** بدقة |

| 👥 **دمج المكررين** *(جديد v1.1)* | يكشف نفس الشخص خلف عدة شرائح (اسم + ولاية/عنوان مشابه) ويدمج السجل بنقرة |

## 🗄️ أين تُخزَّن بياناتي؟

<div dir="rtl">

مجلد واحد فقط، سهل النسخ الاحتياطي أو النقل على فلاشة:

| النظام | الموقع |
|---|---|
| Windows | `%APPDATA%\Himaya\himaya.db` |
| Linux/Mac | `~/.himaya/himaya.db` |

- `himaya.db`: **كل** التطبيق (الزبائن، الطلبيات، القائمة السوداء…)
- `evidence/`: نسخ مؤرخة من الوصولات المزيفة المحللة
- `backups/`: النسخ الاحتياطية (زر *نسخ احتياطي الآن* في الإعدادات)

يمكن وضع قاعدة البيانات في مكان آخر (مثلاً مباشرة على فلاشة) عبر
`HIMAYA_DATA_DIR` أو `python main.py --db المسار`.

</div>

## 🔐 صيغة .hma (المشاركة دون إنترنت)

<div dir="rtl">

ملف `.hma` هو مستند JSON موقّع بترويسة `HIMAYA-BLACKLIST`، مقروء من أي
نسخة من حماية ويمكن فحصه بأي محرر نصوص:

</div>

```json
{
  "magic": "HIMAYA-BLACKLIST",
  "version": 1,
  "exported_at": "2026-09-04T15:30:00",
  "count": 2,
  "entries": [
    {"phone": "0770999888", "reason": "وصل BaridiMob مزيف", "severity": 3,
     "reported_date": "2026-09-01"}
  ]
}
```

<div dir="rtl">

الاستيراد **يدمج** (الخطورة الأعلى تتفوق) — بياناتك لا تُستبدل أبداً.

## 🧠 نقطة الثقة — كيف تُحسب

الجميع يبدأ من **50/100** (جديد). كل طلبية تحرك النقطة:

| الحدث | التأثير |
|---|---|
| تم التوصيل | +10 |
| مدفوعة | +15 |
| وهمية (شبح) | −25 |
| مرفوضة | −12 |
| الهاتف مغلق | −10 |
| دفع مزيف | **−45 وتُثبّت عند 10** |
| ملغاة | −6 |
| محجوبة (قائمة سوداء) | −35 وتُثبّت |

موثوق ≥ 80 (مع 3+ توصيلات) · ⚠️ حذر 40-79 · 🚨 خطر أقل من 40.

**الاصطلاحات المالية:** الإيراد = الطلبيات *المدفوعة* · خسارة الطلبية الوهمية/المرفوضة/الهاتف المغلق = مصاريف التوصيل · خسارة الدفع المزيف = المصاريف + السعر الكامل · **المال الموفَّر** = مصاريف التوصيل المتجنبَة على الطلبيات *المحجوبة* قبل الإرسال.
